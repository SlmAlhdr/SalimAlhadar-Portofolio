# Foto untuk portofolio

Salin foto profil dan gambar proyek ke folder ini. Contoh nama:

- foto-saya.jpg
- website-kedai-kopi.png

Lalu isi jalurnya di ../js/portfolio-data.js, misalnya assets/images/website-kedai-kopi.png.
Gunakan gambar yang Anda punya hak untuk tampilkan. Format JPG, PNG, dan WebP dapat digunakan.
